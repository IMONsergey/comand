# Comand Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent modules; root integrates and independently verifies.

**Goal:** Deliver and publish a working self-owned remote task system with real device execution and ChatGPT-compatible MCP.

**Architecture:** Single-owner durable hub plus outbound-poll Mac/Linux agents. Detached execution supervisors survive network/daemon restarts; project locks and idempotency prevent unintended repetition. Web UI and MCP share one API/store.

**Tech Stack:** Node >=24, TypeScript, native SQLite, Express 5, MCP SDK, React/Vite, Playwright.

**Spec:** docs/superpowers/specs/2026-10-31-comand-design.md

## Global Constraints

- Protocol is src/shared/protocol.ts; change it only through root coordination.
- No auto-retries of accepted execution, no unauthenticated remote shell, no committed secrets.
- Uncertainty remains explicit and project-blocking.
- Node >=24, Russian UI, no mock production data or cloud services.
- Each worker owns disjoint paths; root alone commits/integrates shared files.

## Review Focus

1. Duplicate job/dispatch after network loss must not repeat a command.
2. Cross-device credentials, CSRF and symlink escape must not bypass boundaries.
3. Cancellation offline is pending until the device confirms the outcome.
4. Worker restart cannot be mistaken for process success or safe retry.
5. OAuth grant/refresh replay, wrong resource/client and stale session must fail.
